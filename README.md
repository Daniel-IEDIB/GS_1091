Este repositorio recoge todo el **código de los proyectos y ejercicios** realizados durante la asignatura _Desarrollo de Entornos Interactivos Multidispositivo_. Está pensado como una **muestra de aprendizaje y práctica en Unity**, mostrando cómo he ido desarrollando mecánicas, control de objetos y sistemas de interacción en entornos 2D y 3D.

Todos los proyectos incluyen scripts organizados para poder estudiar cómo se aplican conceptos de físicas, control de personajes, cámaras y lógica de juego en Unity. El foco está en el **código y las soluciones implementadas**, no en los assets o builds finales.

## Qué he aprendido y practicado

-   Manejo de Unity y C# para crear interacciones jugables.
    
-   Control de objetos con físicas (`Rigidbody`, `Collider`) y movimiento responsivo.
    
-   Gestión de inputs y sistemas de interacción con el jugador.
    
-   Organización de scripts y estructuras de proyecto para mantener código claro y reutilizable.
    
-   Conceptos básicos de cámaras, animaciones y feedback visual que mejoran la experiencia de juego.
    

Este repositorio sirve como **referencia de mi progresión** en la asignatura y como base para futuros proyectos en Unity.
